# Gross Domestic Suffering

Source for [grossdomesticsuffering.org](https://grossdomesticsuffering.org), an open index that ranks countries by preventable human and animal suffering.

## Structure

- `index.html`, `styles.css`: the homepage and shared styles (static, served by GitHub Pages)
- `about/`, `faq/`, `blog/`: inner pages, generated by `tools/site/build.py` (edit content in `tools/site/posts.py` and `build.py`, then run `python3 -I tools/site/build.py .`)
- `images/`: openly licensed photos (credits are in the site footer)
- `robots.txt`, `sitemap.xml` (regenerated by the build), `404.html`, `favicon.svg`: SEO and site basics
- `gds-model-v1/`: the 2022 prototype notebook and data
- `pipeline/`, `data/`: the GDS v2 index pipeline (`fetch.sh` → `extract.py` → `build_index.py`) and its outputs in `data/output/`
- `docs/gds-v2-plan.md`: v2 indicators, formula and first results; `docs/gds-index-plan.md`: earlier roadmap

## Local preview

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000.
